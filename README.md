# アプリプライバシーポリシー

本ウェブサイトは、提供するスマートフォン向けアプリケーション（以下、「本アプリ」）におけるユーザー情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

## 1. 取得する情報および利用目的
本アプリでは、広告配信やアプリの利便性向上・改善のために、以下の第三者配信事業者が提供するサービスを利用して情報を自動取得する場合があります。

* **広告配信事業者:** Google AdMob
* **利用目的:** ユーザーの興味・関心に応じた最適化広告の配信、および広告効果の計測
* **取得する情報:** 広告識別子（AAID / IDFA）、端末情報、ログ情報など

詳細については、[Google 広告ポリシーと規約](https://policies.google.com/technologies/ads?hl=ja) をご確認ください。
