デリバリ電卓 プライバシーポリシー
（旧名称：フーデリ電卓）

1. 個人情報の収集について

本アプリ「デリバリ電卓」は、氏名・住所・電話番号等、ユーザーを直接特定できる
個人情報を取得・保存・第三者提供することはありません。

2. アクセス解析ツールについて

本アプリでは、アプリの利用状況を把握するため、Google Firebase Analyticsを
使用しています。Firebase Analyticsは画面の閲覧状況や操作履歴等を収集しますが、
氏名・メールアドレス等、個人を特定する情報は収集しません。
収集された情報はGoogle社のプライバシーポリシーに基づき管理されます。
https://policies.google.com/privacy

3. 広告配信について

本アプリでは、広告表示のためGoogle AdMobを使用しています。AdMobは広告の
配信・表示回数の測定・不正防止等の目的で、広告識別子(広告ID)等の情報を
収集する場合がありますが、氏名・メールアドレス等、個人を特定する情報は
収集しません。
収集される情報の詳細は、Google社のプライバシーポリシーをご確認ください。
https://policies.google.com/privacy
広告のパーソナライズを希望しない場合は、端末
プライバシー > 広告)から広告IDのリセットやオプトアウトが可能です。
